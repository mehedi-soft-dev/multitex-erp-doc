# Accounting module documentation

Source-of-truth docs for the Accounting module, one file per screen/menu ("feature") and one
file per Oracle table ("schema"). This follows the same convention as the sibling repo
`MultitechERP`'s `docs/` tree (see `MultitechERP/docs/CONTRIBUTING.md` and
`MultitechERP/docs/10-knowledge-graph.md`) so a script can mechanically derive a graph from the
docs instead of a human hand-maintaining a separate graph file.

## For AI agents

1. Look for `docs/accounting/features/{slug}.md` for the screen you're asked about. If found,
   that's the answer — stop.
2. For column-level questions, check `docs/accounting/schema/{TABLE}.md`.
3. If still missing, check the graph (`.agent/knowledge-graph/{nodes,edges}.jsonl`, regenerate
   with `python .agent/knowledge-graph/harvest_graph.py`) before grepping source.
4. The Oracle package source (`PKG_ACCOUNTING.sql` and related packages) is not in this repo —
   see `CLAUDE.md`'s "Sibling repo" section for its location in `MultitechERP`.

## How to read this

- [features/_index below](#features) — one file per menu/screen, YAML front-matter + prose
  (Overview, Fields, Relationships, Known Issues, Unused Columns)
- [schema/_index below](#schema) — one file per Oracle table, column list merged from every
  feature that touches it
- Graph (generated — do not hand-edit): `.agent/knowledge-graph/nodes.jsonl`,
  `.agent/knowledge-graph/edges.jsonl`, regenerate with
  `python .agent/knowledge-graph/harvest_graph.py`

## File layout

```
docs/accounting/
  README.md                # this index
  features/
    {slug}.md               # one per menu/screen — id: feat:acc-{slug}
  schema/
    {TABLE_NAME}.md          # one per Oracle table — id: tbl:{TABLE_NAME}

.agent/knowledge-graph/
  harvest_graph.py           # regenerates nodes.jsonl/edges.jsonl from the front-matter above
  nodes.jsonl, edges.jsonl   # generated — never hand-edit
```

## Previous format (superseded, read-only)

Before 2026-09-14 this module was documented as 5 markdown files per menu
(`01-overview.md` .. `05-unused-columns.md` under `docs/accounting/{master-data,transaction,reports}/NNN_slug/`)
plus a hand-duplicated Excel workbook (`Accounting_Module.xlsx`, generated by
`docs/accounting/scripts/build_accounting_doc.py`) and a separately hand-maintained
menu-level knowledge graph. That format is preserved, unmaintained, at
`backup/accounting-docs-2026-09-14/` (old docs + xlsx + generator script) and
`backup/agent-knowledge-graph-menu-style-2026-09-14/` (old graph) — every fact from it was
carried forward losslessly into the `features/*.md` + `schema/*.md` files below. The live tree no
longer has the per-menu folders, the xlsx, or its generator script; do not try to regenerate the
xlsx or resurrect that layout — add/edit a `features/*.md` file instead (see `CLAUDE.md`).
